# スキャンツール（iPhone用 Webアプリ）

Safari で開いて「ホーム画面に追加」すると、アプリのように使えるスキャンツールです。
Claude の中ではなく **ふつうの Safari で動く**ので、カメラを直接使えます。

- **撮影中に紙の四隅を追いかけ、止まったら自動で撮影**（vFlat と同じ流れ）。続けて何枚でも
- 撮った写真は台形補正・影除去・本の反り補正をして、フォルダに保存（**iPhoneの中だけ**に保存）
- サムネイルを**横になぞって選択** → まとめて文字化／文字付きPDF／TeX
- 写真アルバムや PDF ファイルの取り込みもできます

## 文字の読み取り方（設定で切り替え）

| 方法 | 内容 | ネット・費用 |
|---|---|---|
| **おまかせ**（おすすめ） | まず iPhone の中でオフライン読み取り。数式がありそうなページや読みにくいページだけ Claude が仕上げる | 必要なページだけ |
| オフラインだけ | iPhone の中だけで読む（日本語・英語の文章向け。数式は TeX にならない） | 不要・無料 |
| 全部 Claude | 全ページ Claude。数式・表まできれいに TeX に | 1ページ数円ほど |

- オフライン読み取りは、初回だけ部品（約20MB）をダウンロードします。以後はネットなしで動きます。
- Claude を使うには、[console.anthropic.com](https://console.anthropic.com) で API キーを発行し、「設定」に貼り付けます。キーはその iPhone の中にだけ保存されます。
- Claude を使ったページの画像は Anthropic に送られます。生徒の個人情報が写ったものは「オフラインだけ」で読んでください。

## 公開のしかた（最初の1回だけ・無料）

カメラを使うため、**https のアドレスで公開**する必要があります（ファイルを直接開いてもカメラは使えません）。
どちらか1つでOKです。

### A. Netlify（いちばん簡単）
1. PC で https://app.netlify.com/drop を開き、無料アカウントを作る（Google アカウントで登録可）
2. このフォルダ（`index.html` などが入っているフォルダ）を、画面にドラッグ＆ドロップ
3. 出てきた `https://〜.netlify.app` のアドレスを iPhone の Safari で開く

### B. GitHub Pages
1. GitHub に新しいリポジトリを作り、このフォルダの中身をアップロード
2. リポジトリの Settings → Pages → Branch を `main` にして保存
3. 数分後に出る `https://ユーザー名.github.io/リポジトリ名/` を iPhone の Safari で開く

## iPhone での使い始め

1. 公開したアドレスを **Safari** で開く
2. 共有ボタン → **「ホーム画面に追加」**
3. ホーム画面のアイコンから開き、「新しいフォルダ」→「撮影」
4. 初回はカメラの許可を聞かれるので「許可」

※ 保存先は「ホーム画面のアプリ」の中です。Safari のタブで開いた場合とは保存場所が別になります。
※ iPhone の空き容量が少ないと、写真が保存できないことがあります。「設定 → 動作の状態を見る」で使用量を確認できます。

## 更新のしかた

`index.html` を差し替えて、もう一度アップロード（Netlify ならドラッグ＆ドロップし直し）するだけです。
保存した写真や文字は iPhone の中にあるので消えません。

## ファイル

```
index.html            アプリ本体（これ1つで動きます）
manifest.webmanifest  ホーム画面に追加したときの名前・アイコン
sw.js                 オフラインでも開けるようにする仕組み
icon-*.png            アイコン
```
